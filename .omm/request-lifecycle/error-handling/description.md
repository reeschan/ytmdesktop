API のエラー (`api-shared/errors.ts`)。`@fastify/error` の `createError` で、コード・文・状態コードを決めておく。

- 400: `INVALID_VOLUME`・`INVALID_REPEAT_MODE`・`INVALID_SEEK_POSITION`・`INVALID_QUEUE_INDEX`・`INVALID_CHANGE_REQUEST`・`INVALID_QUEUE_ADD_REQUEST`・`AUTHORIZATION_INVALID`
- 401: `UNAUTHENTICATED` / 403: `AUTHORIZATION_DISABLED`・`AUTHORIZATION_DENIED`
- 503: `AUTHORIZATION_TOO_MANY`・`YOUTUBE_MUSIC_UNVAILABLE` / 504: `AUTHORIZATION_TIME_OUT`・`YOUTUBE_MUSIC_TIME_OUT`

`isDefinedAPIError` が `errorCodes` に入っているかを見て、サーバーのエラーハンドラーが中身を返すか隠すかを決める。新しいエラーは `errorCodes` にも足す必要がある。
