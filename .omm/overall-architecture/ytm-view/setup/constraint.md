YTM の要素名・セレクター (`ytmusic-search-box`、`ytmusic-app-layout>ytmusic-player-bar`、`#player-page #tab-renderer` など)、内部のイベント (`yt-navigate` / `yt-action` / `yt-service-request`)、ストアのアクション (`SET_CAST_AVAILABLE`)、内部 API (`/youtubei/v1/browse`) に頼っている。YouTube Music が予告なく変えると、その機能だけが黙って効かなくなる (多くは要素が見つからないと何もせず戻る)。`createAdditionalPlayerBarControls` には「新しいプレイヤーバーで一部壊れている (10/03/26)」というコメントがある。
