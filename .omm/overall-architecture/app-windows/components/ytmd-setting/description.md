`YTMDSetting.vue`。設定画面の 1 項目を描く汎用コンポーネント。`type` (generic: `checkbox` / `file` / `range` / `select` / `text` / `custom`) で入力の形が変わり、名前・説明・再起動が要るか (`restartRequired`)・無効とその理由・Beta 表示・字下げ・select の選択肢 (`optionsMap` / `optionsOrder`)・file の `accept` と `bindSetting` (どの設定に書くかを `data-setting` に入れる) を props で受ける。値は v-model (`update:modelValue`) で返し、`change` / `file-change` / `clear` を emit する。`custom` はスロットで中身を差し込む。
