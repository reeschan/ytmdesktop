# 背景動画は YTM 画面の中に差し込まず、YTM 画面の下に置く専用のビューで流す

背景動画とマスクは、背景動画専用のアプリのビュー (WebContentsView) に置き、YTM 画面 (music.youtube.com を表示する WebContentsView) のさらに下に付ける。背景動画が有効な間は YTM 画面の背景を透明にして、下の動画が透けて見えるようにする。ローディング画面のビューは YTM 画面の上にあり、YTM の準備ができると隠れるので、背景動画の置き場には使わない。

YTM 画面の DOM に `<video>` を差し込む案も考えたが、採らなかった。理由は次の 3 つ。

- YTM 画面は別のセッション (partition) で動いていて、アプリ内のプロトコルでローカルの動画を渡しにくい。
- YTM の CSP で、動画の読み込みを止められるおそれがある。
- YTM の DOM が変わると、差し込んだ要素が壊れたり消されたりする。

専用のビューに置けば、動画の再生とマスクはアプリが作る画面の中で完結する。YTM 画面に求めるのは、背景を透明にすることだけになる。

## Consequences

- YTM 画面の背景を透明にする CSS は、YTM 側の変更 (背景色を直接書いている箇所の増減) に合わせて直すことがある。
- ビューの重なり順 (下から順に、背景動画のビュー、YTM 画面、ローディング画面) を変えると、背景動画が見えなくなる。
